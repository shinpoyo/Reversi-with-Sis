# コミック接待オセロ 〜姉ちゃんの機嫌を損ねずに勝て！〜

8×8の本格オセロ対局に、マンガ・アニメ風のコマ割り演出、4段階の姉ちゃん表情変化、カットイン、ちゃぶ台返しを搭載したブラウザゲームです。

## すぐ遊ぶ方法
`index.html` をブラウザ（Chrome / Safari / Edge など）で開くだけでそのままプレイできます（画像・効果音すべて `index.html` 内に内蔵済みのため、単一ファイルでも動作します）。

## GitHub Pages での公開手順
1. GitHub で新しいリポジトリ（例：`settai-othello`）を作成します。
2. このフォルダ内の `index.html`（および画像ファイル）をそのままアップロード（Commit）します。
3. リポジトリの **Settings > Pages** を開き、**Branch** を `main`（または `master`）にして **Save** を押します。
4. 数十秒待つと、`https://<あなたのユーザー名>.github.io/settai-othello/` で公開され、スマホでもPCでもURLひとつで遊べるようになります！
